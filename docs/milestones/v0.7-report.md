# v0.7 report — multi-agent orchestration, A2A, optional Temporal

Date: 2026-10-29. Owner identity: Venkatesh Goshika / `goshikavs`. No Cursor/AI authorship.

## 1. Features implemented

- Native parent/child runs, `AgentGroup` / `AgentTask` / `CoordinationPolicy` in Rust + Python + TypeScript
- Verified delegation: child `COMPLETED`/`VERIFIED` ≠ parent `VERIFIED`
- Versioned shared context with OCC and immutable history
- Parent cancel propagates to descendants; deferred coordinators survive restart without `RECOVERY_REQUIRED`
- A2A protocol **1.0** JSON-RPC subset (Agent Card, SendMessage, GetTask, CancelTask)
- Studio multi-agent panel from `GET /hierarchy`
- Examples: retail refund team, insurance policy-version invalidation, two-process A2A
- Temporal adapter **explicitly deferred** (`docs/architecture/temporal-comparison.md`)

## 2. APIs and schemas

## 5. A2A interoperability

- Axiom Agent Card `protocolVersion` 1.0 JSON-RPC at `http://127.0.0.1:7400/a2a`
- Independent peer: `examples/a2a-collaboration/peer.py`
- Matrix tests ignore `markVerified` and keep `axiomVerificationStatus=NOT_EVALUATED` on A2A-created runs
- Unsupported: gRPC, HTTP+JSON, streaming, push, extended card

## 13. Known limitations

- MCP demo server: **2024-11-05** stdio Content-Length only. Not resources/prompts/sampling; not a wrapper around the official SDK. Official SDK 1.32.2 did not finish initialize against that server in this probe.
- OpenAI Agents SDK: **tracing-only** (0.24.0 TracingProcessor). `Runner.run` is not demonstrated offline.
- A2A: JSON-RPC subset only.
- Temporal: not implemented.
- Child `success=lambda True` in examples is for subtask completion; parent predicates still read the store.
- Studio screenshots not attached unless Playwright is run with Studio up.
- `target/debug/axiom-server.exe` is the binary used; stop processes on 7400 before rebuild (Windows file lock).
