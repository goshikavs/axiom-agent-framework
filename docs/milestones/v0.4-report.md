# v0.4 report — OpenTelemetry and framework interoperability

**Status:** IMPLEMENTED_AND_TESTED against live `goshikq-server` + PostgreSQL on this host (2026-10-29).

## What shipped

- OTLP/HTTP `POST /v1/traces` and `POST /api/v1/otlp/v1/traces` accept protobuf (`ExportTraceServiceRequest`) and JSON.
- Mapping version `otel-genai-v1` in `goshikq-core` (IO-free). Missing attributes stay unknown. Prompts redacted unless `GOSHIKQ_CAPTURE_MODEL_IO=full`.
- Token usage keys (`input_tokens`, `output_tokens`, `cached_tokens`, `total_tokens`) are treated as usage counts, not secrets.
- External `run.completed` becomes run status **UNVERIFIED** and verification **NOT_EVALUATED**. No goal/verification events are fabricated from traces.
- Auth: `Authorization: Bearer` or `x-api-key` when `GOSHIKQ_AUTH_MODE=api_key`. Project mismatch via `X-Goshikq-Project-Id` or `goshikq.project_id` is forbidden (403). Payload size, span count (2000), and per-project rate limits apply.
- Capability manifests: `GET /api/v1/capabilities`. Studio Integrations shows persisted rows plus the manifest list.
- Examples: `examples/langgraph-refund` (real LangGraph `StateGraph`), `examples/openai-agents-refund` (SDK hooks or mock OTLP).
- Studio execution header shows `source_framework` and “Goshikq did not control this execution” for non-native runs. Inspector lists missing attributes.

gRPC OTLP is **not** implemented.

## Limitations

- Goshikq does not control LangGraph or OpenAI Agents SDK actions.
- Traces are not verified business outcomes.
- Cross-project isolation is API-key / project-id scoped. Local `GOSHIKQ_AUTH_MODE=none` is loopback-only; mismatch header still returns 403. Two-project API-key isolation was not re-run as a live pair in this cycle.
- Token usage appears only when the producer sends GenAI/OpenInference attributes.
- Duplicate span handling is idempotent on deterministic `event_id`; out-of-order spans keep source time.
- LangGraph `agent_name` may be the first classified CHAIN span (e.g. `lookup`), not a user-chosen agent id.
