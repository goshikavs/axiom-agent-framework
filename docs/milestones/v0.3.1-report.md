# v0.3.1 report — research and benchmark validation

**Status:** IMPLEMENTED_AND_TESTED on this host. Not a product performance claim. Not a claim that Axiom detects unregistered dependencies.

## Features implemented

- Four **independent** revalidation strategies in `crates/axiom-core/src/baselines.rs`:
  - A `none` — empty prediction
  - B `full_declared` — any registered hit → recheck every declared decision/action/approval
  - C `conventional_prewrite` — version-check `resource_id` on action nodes only (no graph walk)
  - D `selective` — existing `compute_impact` on the declared graph
- Seeded generator (`ChaCha8Rng`) for sizes 10, 100, 1_000, 10_000 with 12 scenario families (unrelated, simultaneous, deleted, inaccessible, missing versions, concurrent, approval delay metadata, external delay metadata, duplicate events, cyclic attempt, missing registered deps, hidden edges)
- Independent ground-truth BFS over declared ∪ hidden edges (`crates/axiom-bench/src/ground_truth.rs`) — does not call `compute_impact`
- Machine-readable output: `benchmarks/evidence/results.json` (2_546_259 bytes) and `benchmarks/evidence/summary.json`
- Unit tests that A–D are not aliases, that generation is deterministic, and that hidden dependents appear in ground truth but not in D

## How to read this (no marketing)

- Ground truth includes **hidden** edges withheld from every strategy. D cannot and does not detect them. That is why D recall is about 0.64, not 1.0.
- B’s recall is 1.0 because hidden edges point at **existing** declared nodes; rechecking every declared node covers those ids at the cost of precision (false-positive revalidation rate 0.75 overall).
- C never walks to decisions. It only version-checks action `resource_id`s. Precision is 1.0 on the nodes it selects; it misses most graph-dependent actions (incorrect-action 0.833, same empty-GT vacuity as A: 2 of 12 families have empty truth).
- A is the no-revalidation baseline. Vacuous precision 1.0 and vacuous recall 1.0 on empty-truth families (unrelated change, missing registered resource) produce overall recall 2/12 = 0.167.
- Latency is in-process wall-clock of the strategy function on this host, release profile. It is **not** end-to-end agent runtime and **not** a production capacity claim.

## Known limitations

- Hidden-edge fraction is generator-defined (~10% extra edges), not a field measurement of real agents.
- Incorrect-action is a trial-level 0/1 if **any** true-graph action was missed; it is strict.
- Approval/external delays do not affect set membership.
- Windows ARM64 native `link.exe` remains unavailable; binary is x64 MSVC.
