# v0.3.2 report — evidence coverage, metric honesty, and action gates

**Status:** IMPLEMENTED_AND_TESTED on this host. Not a claim that unknown dependencies are solved.

## Benchmark metric definitions

Let \(P\) be predicted node ids (decisions ∪ actions ∪ approvals). Let \(T\) be the true-graph affected set (declared ∪ hidden BFS, independent of `compute_impact`). Let \(R\) be the declared-graph affected set. Let \(H = T \setminus R\) (hidden-only).

| Metric | Formula | Vacuous case |
|---|---|---|
| Precision | \(\|P \cap T\| / \|P\|\) | empty \(P\) → 1 |
| True-impact recall | \(\|P \cap T\| / \|T\|\) | empty \(T\) → 1 and `vacuous=true` |
| Registered-impact recall | \(\|P \cap R\| / \|R\|\) | empty \(R\) → 1 |
| Hidden-detection recall | \(\|P \cap H\| / \|H\|\) | empty \(H\) → vacuous |
| False-negative rate | \(1 -\) recall on the same denominator | flagged vacuous |
| Action-prevention recall | \(\|P_a \cap T_a\| / \|T_a\|\) | empty \(T_a\) excluded from non-vacuous mean |
| Incorrect-action rate | 1 if any \(T_a \setminus P_a\), else 0 | trial-level |
| False-block rate | \(\|P_a \setminus T_a\| / \|P_a\|\) | empty \(P_a\) → 0 |
| Verification workload | \(\|P\|\) | |
| Latency | wall-clock ns of the strategy function | |
| `trivial_full_selection` | selected every declared decision and action | |

### Why full-declared reported 100% recall in v0.3.1

Hidden edges in the generator land on **existing declared node ids**. Full-declared selects every declared decision/action/approval after any registered hit, so those ids are in \(P\). That is **selection of all declared nodes**, not detection of hidden edges. Tests fail if `true_impact.recall == 1` on a hidden-only set is reported without `trivial_full_selection`.

The four questions are now separate: (1) true-impact detection, (2) registered-impact detection, (3) full decision selection, (4) action prevention.

v0.3.1 A–D **outputs are unchanged**. Only labels, extra metrics, and policies E/F were added.

### E–F (new policies)

| Strategy | True-impact recall nonvacuous | Hidden-detection | Action prevention | Incorrect-action | False-block | Workload | Latency |
|---|---|---|---|---|---|---|---|
| E selective+prewrite | 0.573 | 0.000 | 0.579 | 0.785 | 0.000 | 3.65 | 223 µs |
| F strict_contract | 0.708 | 0.297 | **0.964** | **0.125** | 0.524 | 148 | 91.6 ms |

On this generator E matches D in set membership: conventional `resource_id` hits are already selective seeds. They **differ** on a unit-test fixture where an action’s recorded version already equals the new version. Do not treat E as an alias.

F reduces incorrect permitted actions (0.785 → 0.125) by blocking tools whose **declared contract** lists the changed resource even when the graph edge is hidden. False-block rate 0.524 is the cost of those extra declared requirements. F does not detect unlisted hidden edges (hidden-detection 0.297, not 1.0). Database overhead N/A. Model cost unknown.

## New contract APIs

- Protocol: `EvidenceCoverageContract`, `RequiredEvidence`, `RevalidationPolicy`, `CoverageStatus`, `GateDecisionKind` on `ToolSpec` (additive, default `SELECTIVE`)
- Core: `evaluate_coverage`, `evaluate_action_gate`, strategies E/F
- Python: `@tool(required_evidence=[...], required_invariants=[...], on_missing_evidence=..., revalidation_policy=...)`
- Runtime: coverage gate before the existing selective prewrite path; events `evidence.coverage_evaluated`, `action.gated`
- Storage: migration `0004_coverage.sql`
- Studio: coverage block on the existing evidence (and verification) pages

## Safety guarantees and limitations

Guarantees (when a contract is declared and policy is `STRICT_CONTRACT` or risk is high):

- Missing/stale/conflicted declared evidence cannot authorize the write
- Invalidated approval cannot authorize the write
- Coverage-complete is not goal VERIFIED
- Selective graph revalidation still runs after coverage

Not guaranteed:

- Detection of requirements the developer did not list
- Detection of LLM-internal dependencies
- Exactly-once external I/O
- That E outperforms D on every graph shape
