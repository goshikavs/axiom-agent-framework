# v0.8 report — executable workflows, CLI, docs, packaging

Date: 2026-10-30. Owner: goshikavs. No commit, push, or package publish in this cycle.

v0.8 is **validated** for the gates below. It is not a production multi-tenant release. Do not start v0.9 until these suites stay green.

## Implemented

- Versioned workflow schema in `crates/goshikq-core/src/workflow.rs` (START, AGENT, TOOL, CONDITION, PARALLEL, JOIN, APPROVAL, WAIT, VERIFY, END).
- Deterministic validation (missing start/end, dangling edges, unreachable nodes, join semantics, unbounded cycles, missing verification, graph size limits).
- Rust execution of **pinned published versions** (`crates/goshikq-runtime/src/workflow_exec.rs`) on the existing `RunExecutor`. Studio does not schedule work.
- Node-level persistence (`workflow_node_executions`) and `GET /api/v1/runs/{id}/workflow-nodes`.
- Studio React Flow editor: palette, validate, save draft, publish, execute, duplicate, version list, import/export, Ctrl+S.
- CLI: `doctor`, `init --template python|typescript`, `run`, `studio`, `agents list`, `runs list|inspect`, `verify`, `workflows validate|publish|run`.
- VitePress site (`docs/site`, `bun run build`).
- Local unpublished packages: Python wheel/sdist, TypeScript tarball.

## Honest limitations

| Area | Status |
|---|---|
| AGENT nodes | Native (`completed: true`) unless `config.spawn: true`. Spawned children need a worker or they time out. |
| TOOL nodes | Native `echo` / declared `result` only. Unregistered tools fail closed. |
| MCP | Stdio NDJSON + Content-Length read fallback. Official `@modelcontextprotocol/sdk` 1.32.2 initialize/list/call **passes**. Streamable HTTP, OAuth, resources, prompts: **not claimed**. |
| A2A | Protocol 1.0 JSON-RPC subset. Independent httpx client test passes. Remote SUCCESS ≠ VERIFIED. |
| Temporal | Deferred. Native executor remains canonical. |
| GitHub / PyPI / npm | Not published. |

Imported workflow JSON is untrusted: validated on publish/run; drafts may be invalid; max 128 nodes / 256 edges / 10_000 steps; body limited by `GOSHIKQ_MAX_BODY_BYTES` (default 4 MiB).
