# v0.5 report — Advanced Goshikq Studio

**Status:** IMPLEMENTED_AND_TESTED on this host (2026-10-29). v0.4 live ingestion gates passed first. v0.6 was not started.

## What shipped

Studio reads persisted runs, events, evidence, and verification rows. No disconnected mock data.

- **Execution explorer** (`/executions`): backend sort/pagination plus URL filters (time, framework, agent, project, model, run status, verification). Columns include project, tokens (unknown if `usage_known` is false), and estimated cost (unknown if `cost_known` is false).
- **Three-panel inspector**: React Flow graph (parent_span_id edges only; last 250 nodes), chronological timeline, typed inspector. Selection syncs when a matching span/event exists.
- **SSE**: history then `EventSource ?after=sequence`; reconnect indicator; pause UI without pausing execution; auto-scroll; terminal `event: end`; payload dedupe by `event_id`.
- **Evidence / state**: source, version, fingerprint, retrieval time, dependent decisions, registered edges, coverage, revalidation, consecutive snapshot before/after when two snapshots exist.
- **Goal verification**: independent tool, dispatch, business-operation, recovery, and verification fields. Imported traces stay UNVERIFIED unless an Goshikq verifier recorded evidence.
- **Historical replay**: GET-only step through persisted events. Playwright asserts no POST/PUT/PATCH/DELETE.
- **Compare**: span_id identity, else event_type+tool/model heuristic; uncertain matches labeled.
- **Failure analysis** (`/errors`): first observed failure, related prior events, recorded recovery attempts. Suggestions are not claimed as proof.
- **Overview metrics**: totals including inconclusive verification, runs-by-framework, p50/p95, tokens, estimated cost, verification overhead (NULL/unknown when no timed `verification_results`). Missing usage is not shown as zero.
- **UI**: dark/light, collapsible nav (Ctrl+[), resizable inspector panels, skeletons, copy/download redacted JSON, status tooltips.
- **Playwright**: 10 passed, 1 skipped (OTLP missing-attribute label depends on which events are in the first page).

## STRICT_CONTRACT false-block (runtime wiring, not A–F)

Live `examples/retail-refund` was failing with coverage `COMPLETE_FOR_DECLARED_CONTRACT` and reason `revalidation policy blocked this write`. Strategy F evaluated coverage with **empty decision facts**, so `required_invariants=["eligibility"]` always looked missing even when `dec:eligibility:*` existed. A–F algorithms were not rewritten. Runtime now passes recorded `DecisionFact`s into `StrategyContext`. When live coverage is complete and `detect_resource_changes` is empty, that action is not extra-blocked. Gate matching no longer uses `spec.name.contains(id)` (empty/substring false positives).

After the fix:

```text
python examples/retail-refund/main.py --fault never_settles

python examples/retail-refund/main.py

```

## Performance / research notes (Phase C)

A–F were **not** retuned. Seeded bench file remains `benchmarks/evidence/results-v0.3.2.json`.

| Topic | Observation |
|---|---|
| STRICT false-block | Wiring bug (F coverage without decision facts). Not hidden-dep detection. Not claimed 100%. |
| Missing required evidence | Still incomplete coverage; high-risk writes block. Independent of goal VERIFIED. |
| Hidden dependencies | Strategy D recall remains < 1 on withheld edges (v0.3.2 table). B gets recall by selecting everything. |
| Verification workload | Overview `verification_overhead_ms` is SUM of timed `verification_results` only; unknown if none. |
| Graph scalability | Studio windows the last 250 graph nodes. Edges still require `parent_span_id`. |
| Large-trace rendering | Timeline is a full list; very large traces should use the event filter. Not virtualized yet. |
| DB query cost | `list_runs` whitelist ORDER BY + COUNT. Overview adds scalar subqueries on `verification_results`. Not micro-optimized. |

Labels kept distinct: true dependency detection, full-selection behavior, action prevention, incorrect permitted actions, false blocking, latency.

## Known limitations

- Playwright “missing telemetry” case is skipped when the first OTLP run’s first events do not include `metadata.missing_attributes`.
- OpenAI Agents live SDK path was not run (`openai-agents` not installed; mock OTLP used).
- Two-project API-key isolation not re-run as a paired live test; header mismatch 403 was.
- Compare heuristics can label `unmatched` when span ids differ across frameworks.
- Historical replay shows the latest GET `/state` as recorded data, not a reconstructed per-step store.
- Graph does not invent time-adjacent edges.
- No v0.6 TypeScript worker or MCP adapter in this milestone.
