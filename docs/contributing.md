# Contributing

See the repository [CONTRIBUTING.md](https://github.com/goshikavs/goshikq-agent-framework/blob/main/CONTRIBUTING.md).

Maintainer: [goshikavs](https://github.com/goshikavs). Do not add AI assistants as authors or co-authors.

Update `docs/IMPLEMENTATION_STATUS.md` when a feature moves between planned, experimental, and available. Do not mark a protocol integration complete because two Goshikq-specific processes talk to each other.
