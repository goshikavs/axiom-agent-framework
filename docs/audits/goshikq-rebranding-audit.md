# Goshikq rebranding audit

**Date:** 2026-11-03  
**Branch:** `refactor/rebrand-goshikq`  
**Remote repository (at audit time):** https://github.com/goshikavs/axiom-agent-framework  
**Later rename:** the GitHub repository was renamed to https://github.com/goshikavs/goshikq-agent-framework on 2026-11-03. Statements below that say the remote name was unchanged describe the audit-time state.  
**Tagline:** Build Agents. Verify Outcomes.  
**Positioning:** Open-source AI agent execution and verification framework.

This document records the Axiom → Goshikq namespace migration. It is a rebrand, not a rewrite. Algorithms, evidence semantics, verification rules, REST paths, and security controls were not changed except where a dual-read compatibility shim was required.

## 5. Database compatibility and migration decisions

**0001–0008 were not rewritten.** Historical `DEFAULT 'axiom'` on `agents.source_framework` and `runs.source_framework` stays in `0001_initial.sql` so already-applied migration checksums remain valid.

**0009 (forward-only):**

```sql
ALTER TABLE agents ALTER COLUMN source_framework SET DEFAULT 'goshikq';
ALTER TABLE runs ALTER COLUMN source_framework SET DEFAULT 'goshikq';
```

Existing rows keep `source_framework = 'axiom'`. Recovery and lease queries treat both `goshikq%` and `axiom%` as first-party. Native event ingestion treats exact `goshikq` and `axiom` as runtime-owned (not external adapters).

### Embedded PostgreSQL

- New clusters: data dir `.goshikq/postgres`, password/database `goshikq`.
- If `.axiom/postgres` already exists and `.goshikq/postgres` does not, that cluster is reused with password/database `axiom`.
- `DATABASE_URL=axiom-embedded` remains accepted.
- Operators with a Compose volume formerly named for Axiom must recreate or rename it to `goshikq-pg`; existing SQL data is otherwise compatible.

## 9. Remaining defects and risks

1. **GitHub repository name** is still `axiom-agent-framework`. Package identifiers already say Goshikq. A GitHub rename needs a separate owner authorization.
2. **OIDC audience default** is now `goshikq`. Deployments that relied on the implicit audience `axiom` must set `GOSHIKQ_OIDC_AUDIENCE=axiom` (or keep `AXIOM_OIDC_AUDIENCE`).
3. **Compose volume name** `goshikq-pg` does not automatically attach a previous Axiom volume.
4. **A2A skill id** `goshikq-delegate` is primary; `axiom-delegate` is a compatibility alias and should be removed in a later major version.
5. **HTTP header and JWT claim aliases** should be deprecated on a published schedule after external clients migrate.
6. **Clippy** still reports pre-existing style warnings (`too_many_arguments`, `print_literal`, and similar). They are unrelated to branding.
7. Local `target/debug/axiom.exe` leftovers may exist from pre-rename builds; they are gitignored artifacts, not source.
8. Registries were **not** published (npm, PyPI, crates.io, Docker Hub, GitHub Releases).
