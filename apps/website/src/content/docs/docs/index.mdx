Goshikq is an **open-source AI agent framework** with a **Rust runtime** for durable execution, multi-agent orchestration, and evidence-backed outcome verification.

**Status:** `0.1.0-alpha` (v0.9.1 in tree). APIs will change. Packages and GitHub Releases are unpublished.

## Core model

A successful tool call is not a verified business result. Goals are predicates on authoritative `StateSnapshot` values. See [verification](/docs/verification/) and [evidence](/docs/evidence/).
